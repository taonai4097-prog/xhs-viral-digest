# 生图配置指南（运营 + 开发共用）

> 适用：极光AIGC 社媒运营系统 · `pipeline/xhs_mvp.py`
> 更新时间：2026-09-01

---

## 一、两种模式（系统自动选，不用手动切）

| 模式 | 触发条件 | 产出 | 适合谁 |
|---|---|---|---|
| **提示词模式**（默认） | `.env` 里没配生图 API | 一份《生图提示词卡片》md，运营复制提示词去豆包/即梦出图 | 没 API 额度、或嫌自动生成效果差 |
| **API 出图** | 配了 `IMAGE_API_BASE` + Key | 直接生成 `cover.png` / `inner1~3.png` 到本地 | 有稳定 API、要批量出图 |

**降级是自动的**：即使配了 API，调用失败（401/超时）也会自动退回提示词模式，流水线不中断。
卡片里会写明失败原因，方便排查。

## 二、开发者：怎么接生图 API

在 `.env` 填四行即可（支持任意 **OpenAI 兼容** 的 `/images/generations` 接口）：

```bash
IMAGE_PROVIDER=auto
IMAGE_API_KEY=sk-xxx                 # 留空则自动复用 LLM_API_KEY
IMAGE_API_BASE=https://api.openai.com/v1
IMAGE_MODEL=gpt-image-1
```

### 已验证/常用的厂商配置

| 厂商 | IMAGE_API_BASE | IMAGE_MODEL | 备注 |
|---|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-image-1` | 文字渲染能力最强，中文也稳 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Kwai-Kolors/kolors` | 国内直连，有免费额度 |
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedream-3-0-t2i-250415` | 字节官方，和豆包同源于 Seedream |

> 模型名以各厂商控制台当前可选列表为准，填错会返回 404/400，系统会自动降级并打印原因。

### 显式覆盖（不看 .env）

```bash
python pipeline/xhs_mvp.py --inject xhs_posts/xhs_xxx.json --provider prompt_only   # 强制只出提示词
python pipeline/xhs_mvp.py --inject xhs_posts/xhs_xxx.json --provider pollinations  # 免费免key（效果一般）
python pipeline/xhs_mvp.py --inject xhs_posts/xhs_xxx.json --provider openai        # 强制走 API
```

## 三、运营：提示词模式怎么用（SOP）

跑完成稿后，目录里会多一个 `xhs_<选题>_生图提示词.md`，打开它：

1. **打开豆包**（或即梦）→ 点「图片」→ 粘贴卡片里的**完整提示词** → 生成
2. 一次出 4 张，**挑最贴正文、构图最工整**的那张
3. **下载不带任何文字的底图**
4. 用 **稿定设计 / Canva** 套模板把标题压上去 → 导出 **1080×1440**
5. 封面 + 3 张内页都照此办理

### 三条铁律

- **别让 AI 在图里写字**。所有生图模型渲染中文都必乱码（这是模型架构问题，不是提示词写得不好）。
  所以系统给每张提示词都强制加了「无文字 / 无水印」，标题靠后期压。
- **别自己改提示词里的风格段**。卡片里「配色 / 风格 / 光照 / 构图 / 负向约束」那一长串是品牌锁，
  删了就会出现「四张图四个颜色」。你只需要确认「画面主体」描述贴不贴正文。
- **同篇所有图必须同一色板**。卡片已保证，别在豆包里额外加风格词覆盖它。

### 免费商用字体（压字用，别用来源不明的）

思源黑体、思源宋体、阿里巴巴普惠体、站酷系列（庆科黄油体 / 高端黑等）。
已有博主因使用未授权字体被索赔，务必确认授权。

## 四、品牌风格锁：怎么改色板

内置两套，在 `pipeline/image_prompt.py` 的 `BRAND_KITS`：

- **小依依依**（小红书 · 个人IP）：奶油白 `#FAF3E0` + 柔粉 `#F4C0D1` + 暖木 `#C8A88A`
- **极光科技**（抖音 · 机构号）：深灰 `#2D2D2D` + 科技蓝 `#4A90D9` + 荧光绿 `#00D4AA`

**不想改代码**：在 `pipeline/` 下放一个 `brand_kits.json` 即可覆盖（参照 `brand_kits.example.json`）：

```json
{
  "小依依依": {
    "label": "小依依依（小红书 · 个人IP）",
    "palette": "奶油白 #FAF3E0 主底 + 柔粉 #F4C0D1 强调 + 暖木 #C8A88A 点缀",
    "style": "极简干净、生活感、真实不做作",
    "lighting": "柔和自然光从左上打入，轻微阴影",
    "composition": "主体居中偏上占画面 60% 以上",
    "negative": "无文字、无水印、无二维码、不堆砌元素"
  }
}
```

切换账号：`IMAGE_BRAND=极光科技` 写在 `.env` 里。

## 五、强制固定字眼（质量门禁）

每次生成的提示词**必定包含**这三个词，由 `image_prompt.py` 自动拼接，人工删不掉：

```
风格统一, 无文字, 无水印
```

对应解决你之前提的三个问题：

| 原问题 | 机制 |
|---|---|
| 四张图四个颜色 | 品牌锁 style block 原样复用（配色/风格/光照/构图写死） |
| 图片没有文字 | 强制「无文字」出底图 + 后期压字（模型渲染中文必乱码，绕不过去） |
| 提示词风格不统一 | 模板引擎统一拼接 + `validate_prompt()` 门禁校验必含词 |

## 六、排查

| 现象 | 原因 / 处理 |
|---|---|
| 一直只出提示词卡片，不出图 | 没配 `IMAGE_API_BASE`。这是默认行为，不是故障 |
| 配了 API 还是降级 | 看卡片里的失败原因：401/403 = key 或模型名错；超时 = 网络；404 = `IMAGE_API_BASE` 路径不对 |
| 出的图带乱码文字 | 模型渲染问题。检查提示词里「无文字」是否还在（别被覆盖），照旧走后期压字 |
| 想换回免费自动出图 | `--provider pollinations`（免 key，但效果一般，已不作为默认） |
| 智谱 CogView 报 401 | 该 key 通常没有生图权限；本项目不默认走智谱，需显式 `--provider cogview` |
