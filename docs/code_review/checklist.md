## B. 正确性

| # | 检查项 | 结论 |
|---|---|---|
| B1 | 改动解决了目标问题？边界（空数据/重复 id/缺列/BOM/全角）处理了？ | ☐ |
| B2 | 幂等：重复跑不翻倍、断点续跑安全？ | ☐ |
| B3 | 长任务不在请求/交互路径里？ | ☐ |
| B4 | 失败路径有可读报错，不吞异常假装成功？ | ☐ |

## C. 安全与隐私

| # | 检查项 | 结论 |
|---|---|---|
| C1 | 外部输入（网络/CSV/文件）校验后才用？ | ☐ |

| C3 | 文件读写不出项目边界？删除有护栏？ | ☐ |

## D. 可维护性

| # | 检查项 | 结论 |
|---|---|---|
| D1 | 分层清晰：入口不掺业务、业务不依赖 HTTP？ | ☐ |
| D2 | 命名表意、无魔法数字、重复代码已抽？ | ☐ |
| D3 | 注释写「为什么」；无整段注释掉的死代码？ | ☐ |
| D4 | Windows 坑已规避：子进程中文列表传参、CSV utf-8-sig、路径分隔符？ | ☐ |
