# 运营 SOP · 说人话版（给真人运营，不需要会写代码）

> 这份文档是给**运营同事**看的。所有方法论文档（`风格分析_*`、`打分卡`）是给 AI/工程师
> 看的"标准操作手册"，你只需要照这份走，AI 会帮你干活，你在几个"该你拍板"的地方点头就行。
> 配套总览：[docs/methodology/README.md](README.md)（主路图）· [首次运行·人闸引导](首次运行_人闸引导_模板.md)（AI 第一次跑必须一步步来）

## 一、一句话说清：这套东西是干嘛的

帮你把一个**小红书账号**从"随便发发"变成"有方向地发"：

> **先看清自己的号 → 想清楚发什么方向 → 去抄同行的爆款思路 → 拍板写哪篇 → 让 AI 出文案和图 → 你审核发布 → 发完看数据 → 数据喂回下一篇。**

整个流程像"先体检、再定食谱、再照着好菜馆的菜单做菜"：
- **体检** = 看你历史笔记哪篇火、为什么火（不是猜，是看数据）
- **定食谱** = 结合你的目标（想当博主？想找项目？）定内容方向
- **抄菜单** = 去搜同行爆款，拆解人家为什么火
- **做菜** = AI 按你的风格写文案、出配图方案，你拍板

## 二、主路唯一（重要！别被带偏）

**本仓库有且只有一条路，先爬"自己的账号"，不是先爬别人。**

```
① 爬自己的账号 → ② 分析自己发过啥 → ③ 你回答几个问题 → ④ AI 做深度调研
→ ⑤ 定你的「风格」（brand.json，AI 以后都按这个风格写）
→ ⑥ 打分卡选方向 → ⑦ 爬爆款验证 → ⑧ 你拍板选哪篇 → ⑨ 成稿 → ⑩ 发布+看数据
```

**常规更新（已经定过风格之后）** 只走 ⑥→⑩，不用每次从头来。

⚠️ 仓库里有个 `examples/demo_search_contents.csv`，那是**给你看格式的样板**（12 条虚构笔记），
**不是用来跑的**。谁要拿它假装"跑通了"，直接拒绝——跑必须用真实爬取的数据。

## 三、每步你要做什么（就 4 件事）

| 阶段 | AI 做什么 | **你做什么** | 产出 |
|---|---|---|---|
| ① 爬自己的账号 | 打开浏览器扫码登录你的小红书，把你主页笔记存下来 | 用**手机小红书扫码**（Microsoft Edge 窗口）| 你的历史笔记数据 |
| ② 现象分析 | 数你发过几类内容、哪篇互动最高 | 不用做 | 分析表 |
| ③ 回答问题 | 给你一份"主权题"问卷 | **认真答**（你是谁/想干嘛/不想暴露啥）——这是 AI 猜不出来的，必须你答 | 口述档案 |
| ④ 深度调研 | 查你的赛道/读者/同行/合规红线 | 不用做 | 调研报告 |
| ⑤ 定风格 | 合并产出你的风格锁 brand.json | **过目，改到你觉得像你** | 风格锁 |
| ⑥ 打分卡 | 列出 ≥10 个方向打分排序 | **拍板选哪个方向** | 方向 |
| ⑦ 爬爆款验证 | 按方向搜同行爆款，验证有人看 | 不用做 | 选题池 |
| ⑧ 内容简报 | 每篇候选写一页纸简报（给谁看/钩子/封面） | **拍板：做哪篇、怎么做**（不是拍裸方向）| 简报 |
| ⑨ 成稿 | 按你的风格写文案 + 配图方案 | 审稿、按提示词生图（豆包/即梦）| 成稿 + 图 |
| ⑩ 发布后 | 发完 24h 拉数据、复盘、评论区找下篇选题 | 在 App 里发布（**最终人闸=你**）| 复盘 |

**你只在 ⓐ③答题 ⓑ⑤⑥⑧拍板 ⓒ⑩发布 时出现，其余 AI 自动。**

## 四、几个你必须懂的"人闸点"（AI 不能替你决定的事）

1. **你是谁 / 账号目标**（③）：AI 永远猜不准，运营代答=瞎猜，必须账号本人/负责人答。
2. **选哪个方向**（⑥）：打分卡只是排序建议，最后你拍。
3. **做哪篇、怎么做**（⑧）：简报过了你才写稿，别让 AI 直接写。
4. **发布**（⑩）：AI 最多推到草稿箱，**发布按钮在你手里**。

> AI 第一次跑这套流程时，必须**一个阶段一个阶段来**，每做完一步停下跟你汇报，你说"继续"才下一步。

## 五、红线（碰了会限流/违规，AI 已经帮你查，但你要知道）

| 红线 | 说人话 |
|---|---|
| 点名其他平台/工具 | 正文别写"我用扣子/豆包/ChatGPT/WorkBuddy…"，会被判打广告限流 → 写"AI 搭建平台"这类 |
| 站外导流 | 别写"加微信/看主页/评论区自取/二维码" → 轻则限流重则封号 |
| 极限词 | 别写"最/第一/100%/根治/包治"这类绝对话 |
| 医疗功效 | 无资质别写"疗效/祛斑/治XX"——医疗内容 2026 新规极严，**你是医学生号尤其注意** |
| AI 标注 | AI 辅助生成的内容发布时必须勾选"AI 辅助创作" |
| demo 数据 | 见上：`demo_search_contents.csv` 只是格式参考，不许拿来跑 |

> 发布前 AI 会跑一遍自查脚本；**但图里的大字、评论区它管不到，你要人眼扫一眼**。

## 六、账号档案放哪（每账号一套，带版本）

```
accounts/<账号id>/
  口述档案_vN.md        ← ③ 你答的问题
  赛道调研报告_vN.md    ← ④ AI 调研
  风格框架_vN.md        ← ⑤ 你的风格（合并结果）
  brand.json            ← ⑤ 机器读的风格锁（AI 写稿都按它）
  选题池_vN_真数据.md   ← ⑦⑧ 候选选题 + 简报
  发布后复盘_第N篇_日期.md ← ⑩ 数据复盘
```

## 七、常见问题（说人话）

- **"为什么 AI 一上来问我是什么领域/要不要打分卡？"** → 它跳步了。正确起点是**先爬你自己的号**（本 SOP 第①步），不是先想方向。让它照 docs/methodology/README.md 的主路走。
- **"扫码扫谁？"** → 扫你自己的小红书。爬虫只爬你扫码登录的那个账号。
- **"什么时候要重跑全流程？"** → 换账号/换大方向时。同一账号常规更新只走 ⑥→⑩。
- **"AI 写的东西不像我？"** → 回去改 ⑤ 的 brand.json / 口述档案，写稿全部按它来。
- **"看不懂 AI 汇报里的词？"** → 让它说人话（这是本项目对 AI 的硬要求），或对照本文档。

## 八、交接给下一位运营的 3 句话

1. 主路：**先爬自己的号 → 定风格 → 选方向 → 拍简报 → 发布看数据**，别被 demo/打分卡带偏。
2. 你只做 4 件事：**答题、拍板（方向/简报）、生图、发布**。
3. 一切看不懂就让 AI 说人话，它必须能解释到你听懂为止。
