# 小红书账号发布后监控复盘 SOP（账号无关模板）— 2026-09-03

> 用途：账号每发一篇后，按固定节奏采集数据 → 算指标 → 归因 → 产出下一个优化动作。
> 出处：企业级/MCN 通行做法（创作者中心 + 专业号后台 + 千瓜/新红三方校准）调研综合。
> 铁律：**看数据 ≠ 复盘**。"打开创作者中心看一眼"不叫复盘；复盘必须产出"下一篇改什么"。

## 二、监控节奏（时间点固定，别天天盯）

| 节点 | 看什么 | 做什么 |
|---|---|---|
| 发布后 **30min–1h** | 初始互动速度 | 黄金窗口——在线回评，保真实互动节奏 |
| 发布后 **2h** | 互动结构 | 阅读低但收藏率>5% → 有长尾潜力，只微调标题首词 |
| 发布后 **6h** | 流量拐点 | 增速放缓但收藏率爬升 → 能进更大流量池 |
| **24h**（本篇重点） | 全套指标 | 第一次完整复盘（见下表） |
| **48h / 7天** | 长尾 | 收藏型内容 7 天仍在涨 → 列为可复用选题方向 |

## 三、核心指标 + 健康基准（企业通用阈值）

| 指标 | 公式 | 合格 | 优秀 | 低于→查什么 |
|---|---|---|---|---|
| **点击率** | 阅读 ÷ 曝光 | ≥5% | ≥8% | <3%：封面/标题吸引力不足 |
| **互动率** | (赞+藏+评+转) ÷ 阅读 | ≥3% | ≥8% | <1%：内容无共鸣（不一定是数据差，新号另看） |
| **收藏率** | 藏 ÷ 阅读 | ≥3% | ≥5% | <2%：干货密度不足，没收藏价值 |
| **赞藏比** | 藏 ÷ 赞 | — | 藏≈赞或更高 | 藏远低于赞：内容"爽"但不"有用" |
| **粉丝阅读占比** | 粉丝阅读 ÷ 总阅读 | 30–50% | <30% 更普适 | >60%：触达新用户弱，选题太垂直/靠老粉 |
| **关注转化** | 关注数 ÷ 主页访客 | — | — | 曝光高主页访问低：主页包装/定位不清 |

> ⚠️ 新号（<1000 粉）阈值要放宽——没有老粉底盘，单篇互动绝对值天然低，**重点看相对趋势**（比上篇好还是差）+ **收藏率**（内容价值信号）而非绝对互动数。

## 四、相对表现 R（本项目已内建，企业核心逻辑）

不看绝对数字，看 **你 vs 同赛道中位** 的倍数：
```
R = 你的某项 ÷ 同赛道该项中位数（用爬虫/analytics 已有基线）
R>1 = 跑赢赛道中位；R>50 = 极端爆款（需复核是否刷量）
```
项目已有：`pipeline/analytics.py` 直接产 R / 热度分 / 反刷量，可对**自己单篇**跑（把基线换成同赛道竞品 CSV）。

## 五、复盘 SOP（每篇 24h 后必做 5 步）

0. **先「去自互动」**（最重要，漏了全盘失真）：发布后你自己点的赞/藏/评/关注一律扣除——爬虫/明细表拿到的是含自互动的数，先减掉你自己的再算指标。跟自己给竞品做的"反刷量"同理，只是对象换成自己账号（2026-09-03 实测教训：含自互动算出 26% 互动率是假象，去水后 10.5%）。
1. **采数**：创作者中心导出/记录：曝光、阅读、赞、藏、评、转、涨粉
2. **算指标**：点击率/互动率/收藏率/赞藏比/粉丝占比（用**去水后**的数）
3. **对照阈值找异常**：哪项低于合格线 = 定位到环节（封面？内容？选题？）
4. **归因**：
   - 点击率低 → 封面标题（门面问题）
   - 互动率低但点击高 → 正文没接住期待（内容空洞）
   - 收藏率低 → 干货密度不足
   - 评论少 → 结尾没有互动钩子/引导
5. **产出一个可执行动作**（不是"多加油"）：如"标题前 6 字加具体人群词""结尾改成提问式""封面大字压痛点"

## 六、决策规则（连续信号才算数）

- **单篇异常 = 偶然，不看**；**连续 3 篇同模式 = 真信号**，才调方向
- 爆款提共性（3 篇 TOP 的共同特征 → 存模板库）；垫底找共性（3 篇 LOW 共同问题 → 止损）
- 每篇复盘必须产出 1 个优化动作，填进下一篇的选题简报
