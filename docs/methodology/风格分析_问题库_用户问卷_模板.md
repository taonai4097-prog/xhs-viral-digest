## 入口分流（第一件事，先答这个）

**Q0. 这个账号是个人还是企业（团队）在运营？**
- [ ] **个人** → 走【个人版】= 一人全权负责，Part 0 + Part 1P + Part 2 全答
- [ ] **企业 / 团队** → 继续问 Q0.1：

**Q0.1（企业才答）你是负责人，还是运营？**
- [ ] **负责人**（定方向者）→ Part 0 + **Part 1E 企业主权题**；Part 2 可交运营
- [ ] **运营**（执行者）→ Part 0 + **Part 2 执行题**；**Part 1E 转交负责人答，禁止代答**

> 分流原则：主权题只有定方向者能答，运营代答=猜（禁止）；执行题运营可答。
> 个人 = 一人既是方向者又是执行者，全答即可。

## 填写指引（给运营 / 使用者）

1. **先答 Q0 入口分流**：个人 → Part 1P；企业负责人 → Part 1E；企业运营 → Part 2（主权题转交负责人）。
2. **主理人在场**：Part 0 确认现象 → 对应版主权题（P/E）→ Part 2 → 存 `口述档案_vN.md`
3. **主理人缺席（默认场景）**：
   - 执行题运营答；主权题**空着**标注"待主理人确认"；用账号数据默认方向推进 MVP，**给候选的每个方向各出一篇示范内容**请主理人对比选；一句话反馈回来就回填。
4. **季度校准**：重看 Part 0 + 主权题（Q3/Q4，企业版含 Q5E 资质复查），更新版本号。
5. **每次成稿前**：只问 Q11，不重复整份。
6. **冲突处理**：客观红线（含资质）> 主理人口述 > 泛化建议；缺主权答案就标注不编。
7. **企业医疗号特别提醒**：Q5E/Q7E 资质答案决定整条内容边界，季度校准必须复查资质与平台规则时效。
