# 选题方向选择打分卡 v2（可执行模板）— 2026-09-03

> 用途：决定"爬哪个方向 / 做什么选题"的系统方法（skill 第 6 步选题闸）。
> 依据：外部企业级同构（InfluencerDB 3-signal / 战略定位矩阵 / 4-factor）+ 黄金十步评估修正。
> v2 修正：① 候选池 ≥10 才打分；② 评分锚点表（判据写死）；③ 总分下限 + 差异化切口维度；
> ④ 明确打分主体（主理人拍权重，Agent 供数据）。
> ⚠️ 量化局限：打分反映"已有数据重心"，对真实痛点/新颖性失效 → **必须配主理人质性闸，分数只是排序建议**。

---

## 步骤 1 · 建候选池（≥10，先扩散后收敛）

来源组合（禁止只靠脑补）：
- 风格框架内容支柱 × 细分切口（每个支柱裂出 3-4 个具体方向）
- 平台信号：小红书搜索下拉词 / 对标爆款评论区高频问题 / 热门话题 / 自己评论区
- 空白位：调研报告"赛道空白位"→ 反向推候选

规则：候选池 <10 → 不进入打分（否则=矮子里拔将军，打出的不是最优是次优）。

## 步骤 2 · 一票否决（任一命中即踢，不参与打分）

- [ ] 碰医疗产品/药品/器械（平台禁达人合作）
- [ ] 需露脸 / 需执业资质 / 需资金投入
- [ ] 需站外导流才成立
- [ ] 与风格框架人设冲突（如与"求职作品集/不露脸"主线矛盾）

## 步骤 3 · 打分（每维 1-5，判据看锚点表）

| 维度 | 权重 | 说明 |
|---|---|---|
| **赛道规模** | | |
| ① 搜索热度 | | 该方向有没有稳定搜索需求 |
| ② 内容供给量 | | 笔记总量（没有=没需求或蓝海，看③辅助） |
| ③ 头部活跃 | | 有没有头部队持续发 |
| **可进入性** | | |
| ④ 头部差距 | | 头部体量 vs 素人能否爆（低粉爆文率） |
| ⑤ 赛道密度 | | 挤了多少同类号 |
| ⑥ 形态匹配 | | 是否你"文字干货"能打（非视频/露脸垄断） |
| **账号契合** | | |
| ⑦ 支柱匹配 | | 是否属风格框架内容支柱 |
| ⑧ 身份/红线匹配 | | 是否需要你没有的资质/露脸 |
| ⑨ 读者匹配 | | 是否你要的读者（想转行人/HR/医学生） |
| **差异化（v2 新增）** | | |
| ⑩ 切口强度 | | 有没有别人没用过的角度/你的独特经历 |

**评分锚点表（判据写死，防凭感觉）**：
- 5 = 强证据（搜索联想首屏可见 / 大量同类但素人仍爆 / 你有独家角度）
- 3 = 中等证据（有稳定搜索 / 有腰部在发 / 角度普通但成立）
- 1 = 弱证据（搜不到 / 头部垄断且新人无爆文 / 需要你没有的条件）
- 具体每题填锚点：如 ①搜索热度 5=搜索栏下拉出词 3=需联想能想到 1=完全搜不到

**总分规则**：
- 一票否决先踢
- 加权平均总分 < 3.0 → 放弃（不许选"相对最好但绝对不够好"）
- Top 2-3 进爬取

## 步骤 4 · 打分主体与权重

- **Agent**：供数据（每个候选的证据、锚点对照）
- **主理人**：拍权重 + 最终拍板（分数只是排序建议，主理人质性判断优先——数据=过去，人=未来）

## 步骤 5 · 爬取与验证

- 爬 Top 2-3 方向关键词 → analytics.py 反刷量（detect_brush）+ 相对表现 R + 热度分 → **真数据才进选题**
- 爬完数据回来 → 与打分卡预估对照（验证打分准不准，季度校准用）

## 步骤 6 · 人闸拍板

给主理人：每个候选 = 分数 + 证据 + 爬回的真数据 → 拍板选哪个方向做第一篇
