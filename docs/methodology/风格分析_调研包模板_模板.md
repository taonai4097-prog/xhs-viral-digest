## 调研前输入（账号先行，双输入）

| 输入 | 来源 | 用途 | 缺失怎么办 |
|---|---|---|---|
| ① 账号现象清单 | 爬账号 → 现象分析（转方向/高互动/内容构成 ≥3 条信号） | 定调研边界与默认方向 | **必做**（无需主理人在场） |
| ② 口述方向 | 问题库主权题（Q1-Q6，主理人答） | 校准方向 | 允许缺；用①的默认方向启动，标注"待确认" |
| ③ 内容侧重 | 问题库执行题 Q7 | 赛道验证哪块有量 | 运营可补 |

> 规则：**先爬账号产出现象清单，再启动调研**；现象清单是无需主理人在场的最小输入。

## 六问调研卡（每问：数据源 / 产出 / 质量门槛）

### ① 读者是谁
- 数据源：平台官方口径 + 行业分析 ≥3 信源
- 产出：读者画像表（身份/年龄/痛点/刷小红书要什么）+ 按内容分支拆表
- 门槛：≥3 独立信源；区分"泛平台画像"与"本账号分支画像"

### ② 赛道参照（同赛道账号 5-10 个）
- 数据源：小红书/百科/行业文章（体量打法可查证者）
- 产出：账号清单表（名称/体量/背景/封面风格/标题套路/内容打法）；分"直接竞品/相近参照/表达范式参照"
- 门槛：≥5 账号；每个可查证；**必须扫描出赛道空白位**（结合账号现象：本账号往哪转、空白在哪）

### ③ 爆文解剖（3-5 篇真实爆款）
- 数据源：真实爆文拆解（点赞/收藏量级可查）+ 运营方法论
- 产出：每篇拆 4 项——为什么爆 / 封面钩子 / 标题钩子 / 结构
- 门槛：≥3 篇真实爆文；给可复制钩子公式，不许只写"内容好"

### ④ 差异化（你的角度别人没有）
- 数据源：综合①②③空白位扫描 + 账号自身笔记数据验证（现象清单）
- 产出：一句话差异化定位 + 依据链
- 门槛：必须有"公开查不到直接竞品"或"竞品弱位"证据；**优先从账号现象里长出来**（如"账号已转向但赛道无人占"）

### ⑤ 内容支柱（4-5 个可反复做的系列）
- 数据源：差异化定位 → 倒推可连载系列；参考现象清单里"哪类你发过且有效"
- 产出：系列表（系列名/给读者/对应差异化）+ 配比建议
- 门槛：每系列能说清"给读者什么 + 为什么你能持续做"

### ⑥ 变现路径（含最新平台规则查证）
- 数据源：平台规则（**必查最新时效**）+ 变现方法论 + 同类案例
- 产出：合规红线清单（必读）+ 可合规变现路径排序 + 不建议碰的
- 门槛：规则带查证日期；医疗/健康类账号必核平台医疗新规（生死线）

## 质量自检（交付前过一遍）
- [ ] 每个"事实"能溯源 URL
- [ ] 赛道账号 ≥5、爆文 ≥3、读者信源 ≥3
- [ ] 规则/政策带查证日期
- [ ] 明确写出赛道空白位 + 依据
- [ ] 输入段标清：用了主理人口述，还是仅账号默认方向（待确认）
- [ ] 没有把"未来可能"当"已经发生"
